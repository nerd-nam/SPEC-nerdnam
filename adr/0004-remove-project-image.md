# ADR-0004: S04 프로젝트 이미지 업로드 제거

- 상태: **결정**
- 날짜: 2026-10-22
- 담당: BE (기획 결정)
- 관련: 기획서 F1·9.2, `design/project.html`, `contracts/화면별-API-목록.md` S04 확인할 것 4

## 배경

기획서 F1의 프로젝트 입력 항목에 "이미지(선택)"가 있어 S04에 업로드 버튼이 있었다. 하지만 올린 이미지를 쓰는 곳이 없었다.

- 다른 화면(S05·S06·S08·S09)에서 다시 보여주지 않는다.
- AI 입력(사례 나누기, 임베딩, 판정, 작성 방향)에 들어가지 않는다. LLM은 언어 모델만 띄우고(ADR-0001) 임베딩도 텍스트만 쓴다.
- 기획서 4.3 데이터 구조에도 이미지 필드가 없다.
- S04 안내 문구는 "포트폴리오 방향을 잡을 때 참고해요"였지만 실제로는 참고하지 않는다.

## 결정

**S04의 이미지 업로드를 MVP에서 뺀다.** 화면, 기획서, API 목록에서 지운다. 링크(GitHub·배포·문서)는 그대로 둔다.

## 검토한 안

| 안 | 판단 |
| --- | --- |
| **A. MVP에서 뺀다** | **채택.** 파일 저장소(S3), 업로드·삭제 API, 탈퇴 시 파일 삭제, 남은 파일 정리 작업이 모두 빠진다 |
| B. 보관용으로만 둔다 | 저장 인프라 비용은 그대로인데 서비스 가치가 작다 |
| C. 사용자가 쓴 이미지 설명을 포트폴리오 방향성(P4·P5)에 글로 넘긴다 | 쓸모는 있지만 MVP 범위 밖. 추후 후보 |

## 추후 다시 넣을 때 (P2 후보)

- **이미지 설명을 포트폴리오 방향성에 쓰기 (C안):** 이미지마다 사용자 설명을 받아 P4·P5에 글로 넘긴다. "3쪽에 올린 아키텍처 이미지 사용" 같은 추천을 하고, 이미 있는 자료는 이미지 프롬프트를 만들지 않는다.
- **이미지 내용을 원문에 보태기:** 이미지를 볼 수 있는 모델이 도식·그래프를 글로 옮기고, 사용자가 확인한 뒤 원문에 덧붙인다. 별도 모델과 GPU 메모리가 필요하다.
- 저장 위치는 그때 정한다. 검토했던 기본안은 AWS S3 서울 리전 비공개 버킷이다. 브라우저가 임시 주소(presigned URL)로 직접 올리고, 회원별 경로로 탈퇴 시 한 번에 지운다.
